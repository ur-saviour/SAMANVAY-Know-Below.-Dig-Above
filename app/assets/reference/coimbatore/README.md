## Important currency and legal-use limits

This is a **legacy reference boundary dataset**, not a current CCMC-certified statutory boundary layer. The source filename and accompanying source notes identify a 2011 reorganisation. Geometry may not represent later jurisdiction changes, current ward notifications or current engineering divisions.

CCMC currently publishes a ward-delimitation page with a delimitation map and Gazette notification. Those current official records must be checked before operational use:
- https://www.ccmc.gov.in/index.php/createpage/delimitation-of-ward

SAMANVAY displays this layer only as an optional visual reference. It must not be used to determine legal jurisdiction, building-permission jurisdiction, road ownership, service entitlement or excavation clearance. Replace it only after obtaining or independently validating a current authoritative GIS boundary dataset.

This file contains administrative polygons only. It contains **no buried pipe, sewer, cable, gas, borewell or utility-route geometry**.
